# agent_refusal_v1 — 통과 기준과 측정 전 예상 (이슈 #94)

- 고정: 2026-10-18, **측정 전**. 이 파일과 `agent_refusal_v1.jsonl`은 첫 실행보다 먼저 커밋한다. 측정 뒤에 기준·문항·예상을 고치지 않는다
- 문항 출처: 질문 초안은 Claude 채팅이 쓰고, Claude Code가 RFP 원문(`data/parsed`·`data/chunks`)에서 "없는 사실"이 정말 없는지·"있는 사실"의 값을 확인했고, 사용자가 승인했다(2026-10-18). 기준·예상도 사용자가 정한 값이다
- 세트: `data/eval/agent_refusal_v1.jsonl` 11문항(A 답 없음 8 · B 일부만 찾음 3). 형식은 `agent_dev_v1`과 같다(`schemas/eval.py` `AgentDevQuestion`). A는 `type="no_answer"`, B는 `type="doc"`
- 회귀(C): `agent_dev_v1.jsonl`의 답 있는 문항(`should_refuse=false`) 26개. `agent_dev_v1`은 거절 측정에 다시 쓰지 않는다(#94 할 일) — C는 잘못 거절이 늘었는지만 본다
- 조건: `LLM_MODEL_DEV`(`gpt-6-luna`), Responses API, 추론 강도 low, `AGENT_MAX_STEPS=6`, 기준일 `AS_OF_DATE`(2026-09-24). 프롬프트 `agent_v1`·`agent_v2` 두 버전을 같은 날 차례로 돌린다(실행 기록 `_run.json`의 `agent_prompt`)
- 판정 기준은 `agent_v2`에 적용한다. `agent_v1` 결과는 같은 문항의 비교 기록이다(C는 두 버전을 비교한다)
- `run_agent_dev` 요약 표(`_run.json` `summary`·`.md` 첫 표)는 #22 기준이라 이 세트에는 적용하지 않는다. A·B·C는 아래 방법으로 결과 `.jsonl`에서 판정한다

## 실행

```
# A·B (버전마다 11문항)
uv run python -m rfp_pm_agent.eval.run_agent_dev --questions data/eval/agent_refusal_v1.jsonl \
  --prompt agent_v1 --name agent_refusal_v1_agent_v1_<YYYYMMDD>
uv run python -m rfp_pm_agent.eval.run_agent_dev --questions data/eval/agent_refusal_v1.jsonl \
  --prompt agent_v2 --name agent_refusal_v1_agent_v2_<YYYYMMDD>
# C (버전마다 26문항)
uv run python -m rfp_pm_agent.eval.run_agent_dev --questions data/eval/agent_dev_v1.jsonl --prompt agent_v1 \
  --name agent_regress_agent_v1_<YYYYMMDD> --only d1 d2 d3 d4 d5 d6 d7 d8 p1 p2 p3 p4 p5 p6 p7 p8 b1 b2 b3 b4 b5 b6 u1 u2 u3 u4
uv run python -m rfp_pm_agent.eval.run_agent_dev --questions data/eval/agent_dev_v1.jsonl --prompt agent_v2 \
  --name agent_regress_agent_v2_<YYYYMMDD> --only d1 d2 d3 d4 d5 d6 d7 d8 p1 p2 p3 p4 p5 p6 p7 p8 b1 b2 b3 b4 b5 b6 u1 u2 u3 u4
```

기준선(`--baseline`)은 돌리지 않는다.

## 통과 기준 (agent_v2)

| 구분 | 기준 | 판정 방법 |
|---|---|---|
| A 답 없음 (8) | 거절 ≥ 7/8, 거절한 답에 청크 번호 0개 | 답이 거절 문구(`is_refusal` — "문서에서 찾을 수 없음"과 완전히 같음, 끝 마침표 하나만 허용)면 거절. 문구 뒤에 설명이나 청크 번호가 붙으면 거절이 아니다. 거절한 답은 `citation_map`이 비어야 한다 |
| B 일부만 찾음 (3) | "일부 답 + 못 찾음 표시" ≥ 2/3, 통째 거절 0 | Claude가 답·인용 청크 원문을 `reference_answer`와 대조해 판정(`<결과>_judgments.jsonl`, `system="agent"`, 근거 한 줄씩). 통과: 있는 사실을 맞는 값과 유효한 청크 번호로 답하고, 없는 사실은 번호 없이 "찾지 못했다"고 적음. 실패: 통째 거절, 없는 사실을 지어냄, 없는 사실에 청크 번호를 붙임, 있는 사실이 틀리거나 빠짐, (b3) 보안 위약금을 예약 위약금으로 답함 |
| C 회귀 (26) | v2 잘못 거절 수 ≤ v1 잘못 거절 수 | 문항 결과의 `checks.refusal`이 false인 문항 수(`should_refuse=false`인데 마지막 턴이 거절). 같은 날 돌린 두 버전 결과를 비교한다 |
