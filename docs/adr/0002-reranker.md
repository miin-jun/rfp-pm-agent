# ADR-0002: 리랭커 — bge-reranker-v2-m3 (후보 N=20)

- 상태: 채택 (2026-09-27)
- 이슈: #16 / PR: #61
- 결정한 사람: 소유자(miin-jun). 측정 결과를 본 뒤의 판단이다
- 관련: [ADR-0001 임베딩 모델](0001-embedding-model.md) — 결정 규칙·측정 조건·전체 결과표는 ADR-0001에 있다

## 상황

1차 검색(임베딩) 결과의 순서를 크로스인코더로 다시 매길지 정한다. 리랭커는 정확도를 올릴 수 있지만
질의마다 후보 N개를 모델에 통과시키므로 지연이 늘어난다.

## 후보와 규칙

- 없음(기준선) vs **BAAI/bge-reranker-v2-m3** (스냅샷 `953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e`), 후보 N=20
- 측정 전에 고정한 규칙(이슈 #16): NDCG@10에 McNemar 틀은 쓰지 않고, **개선폭과 p95 지연 증가를 함께 보고**한다
- 한국어 파인튜닝 변형 리랭커는 이번 범위 밖으로 두었다(아래 "후속")

## 결과

세 임베딩 모델 각각에 대해 같은 리랭커를 붙였다(run_id는 ADR-0001 결과 절).

| 임베딩 | MRR 없음 → 있음 | NDCG@10 없음 → 있음 | 개선폭 (NDCG@10) | R@10 전부 없음 → 있음 | 리랭크 추가 지연 p50 / p95 |
|---|---|---|---|---|---|
| **KURE-v1** | 0.317 → **0.474** | 0.380 → **0.506** | +0.126 | 30 → 31 | 210 / **483ms** |
| bge-m3 | 0.280 → 0.443 | 0.327 → 0.475 | +0.148 | 25 → 29 | 280 / 570ms |
| e5 | 0.319 → 0.473 | 0.374 → 0.509 | +0.135 | 28 → 32 | 333 / 704ms |

- 리랭커는 상위 20개의 순서만 바꾼다. 세 모델 모두 51문항 전부에서 리랭크 전후 상위 20 집합이 같았고,
  R@20(전부 적중)도 같았다(KURE 32, bge-m3 30, e5 33 — 2026-09-26 확인)
- 같은 리랭커인데 추가 지연이 임베딩 모델마다 다르다. 넘겨받는 후보 20개가 달라서로 보이지만 원인은 재지 않았다(미확인)
- 리랭커 VRAM: 로드 뒤 증가분 1251 MiB (임베딩 서버와 함께 띄워 합계 2502 MiB, 리랭크 실행 중 최대 2726~2918 MiB)
- 태그별로 보면 KURE-v1 + 리랭커에서 multi_chunk R@10 전부 적중이 3 → 2로 줄었다(나머지 행은 같거나 늘었다)

## 결정과 이유

**bge-reranker-v2-m3를 후보 N=20으로 채택한다.**

- KURE-v1 기준 MRR 0.317 → 0.474, NDCG@10 0.380 → 0.506으로 상위 순위가 뚜렷하게 좋아졌다
- 추가 지연은 p95 최대 약 0.5초(KURE-v1 483ms)로, 이후 LLM 답변 생성 시간에 비해 작다고 판단했다
  (LLM 답변 생성 시간은 이번에 재지 않았다)

## 한계

- 51문항·1회 측정이다. 개선폭이 통계적으로 확정된 것은 아니다(규칙상 검정하지 않음)
- 지연은 로컬 RTX 4050에서 임베딩·리랭커 서버를 함께 띄운 상태의 값이다

## 후속

- **#19 거절 로직 경고**: 답 없음 6문항의 리랭커 1위 점수가 0.036~**0.923**으로 넓게 퍼져 있다
  (KURE-v1 + rr: q032 0.426, q034 0.784, **q045 0.923**, q047 0.036, q056 0.695, q057 0.047).
  답이 없는데도 0.9가 넘는 경우가 있어 **점수 임계값만으로 거절하기는 어렵다**. 답 있는 문항의 1위 점수
  분포는 이번 기록에 없어서(미확인) 두 분포의 겹침은 #19에서 따로 확인해야 한다
- 한국어 파인튜닝 변형 리랭커를 후보로 추가해 같은 조건으로 비교한다
- 평가 세트를 늘리면 다시 측정한다 (#25)
- 후보 N=20은 고정값이었다. N을 바꿨을 때의 정확도·지연은 재지 않았다
