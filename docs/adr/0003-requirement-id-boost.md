# ADR-0003: BM25 요구사항 ID 정확 일치 — 쿼리 쪽 requirement_id 가산

- 상태: 채택, 측정 전 (2026-10-06)
- 이슈: #75 / PR: (미정)
- 결정한 사람: 소유자(miin-jun). **측정 전에 고정한 판단**이다. "결과" 절은 측정 후 채운다
- 관련: [ADR-0001 임베딩 모델](0001-embedding-model.md), 이슈 #18(하이브리드 검색), #70(BM25 기준선 조사)

## 상황

OpenSearch BM25 기준선(run `20261005T114207Z-os-bm25`, R@10 전부 적중 19/51)에서 tag:exact 문항이
0/2였다(k-NN은 2/2). q041("…의 SFR-013 요구사항은 어떤 업무를 지원하는 기능인가요?")은 정답
`73c61cba5e928858:block_requirement:SFR-013`이 상위 10 밖이었다. 하이브리드 검색(#18 PR ②)에서
BM25가 맡아야 할 "정확한 ID 질문"을 지금은 처리하지 못한다.

**측정 전에 알려진 위험**: `requirement_id`가 `SFR-013`인 청크는 인덱스 전체에 4개 문서(73c61cba…,
d3e23c59…, 944b2d14…, c6d225f1…)에 하나씩 있다. ID 가산은 문서를 가리지 않으므로 다른 문서의
SFR-013 3개도 함께 올라온다(2026-10-06 조회에서 q041 가산 시 정답 1위, 다른 문서 SFR-013이 2~4위).
상위 10 안에는 들어오므로 R@10 예상은 그대로 두지만, 다른 질문에서는 정답이 1위가 아닐 수 있어
MRR 개선폭은 작을 수 있다.

## 조사 결과 (2026-10-06)

- `text` 필드 분석기(`korean`): `nori_tokenizer`(decompound_mode `mixed`) + `nori_part_of_speech` +
  `lowercase`. 정의는 `src/rfp_pm_agent/ingest/index_mapping.json`
- 이 분석기에서 `SFR-013` → `sfr` / `013` 두 토큰으로 나뉜다
- 문서 `73c61cba5e928858`의 청크 191개 중 본문에 `sfr` 토큰이 든 청크가 15개다(SFR 요구사항 청크
  13개 포함). `sfr`로는 SFR-013을 구분하지 못한다
- `requirement_id`(keyword) 필드가 이미 색인되어 있다. 정답 청크 값은 `"SFR-013"`

## 후보

| | 방법 | 재색인 | 영향 범위 |
|---|---|---|---|
| **A** | 질문에서 요구사항 ID를 정규식으로 찾아 `requirement_id` 정확 일치 조건을 should로 추가 | 없음 | ID가 있는 질문만 |
| B | 분석기를 바꿔 ID를 한 토큰으로 유지 | 3,499건 | 모든 검색 결과가 바뀔 수 있음 |

## 측정 전에 고정한 결정 (이슈 #75 "결정 (2026-10-06)")

- **ID 패턴**: 영문 2~5자 + 하이픈 + 숫자 2~4자리(예: SFR-013, SER-001). 대문자로 정규화한다
- **가산값**: 100 고정. 이 문서에서 BM25 1위 점수가 약 80(q041 기준 80.03)이라, ID가 일치하는 청크가
  확실히 위로 오도록 정한 값이다. 측정 후 조정하지 않는다
  - 쿼리 형태: `constant_score`(filter = `requirement_id` term, boost 100). `term`에 boost를 주면 keyword
    필드도 BM25로 점수가 매겨져 100 × idf가 더해진다(q041 `SFR-013`은 약 +454) — 결정의 "가산값 100"을
    그대로 지키려고 이 형태를 골랐다(2026-10-06 보완)
  - 질문에 ID가 여러 개면 ID마다 조건을 하나씩 둔다(중복 제거, 질문에 나온 순서)
- **ID가 없는 질문**: 쿼리는 지금(`{"match": {"text": 질문}}`)과 완전히 같다
- **판정**: BM25 기준선 19/51(run `20261005T114207Z-os-bm25`) 대비 R@10 전부 적중, McNemar 정확검정
- **예상**: tag:exact 0/2 → 2/2, 전체 19~21/51, ID 없는 문항은 결과 변화 없음

## 결정과 이유

**A를 채택한다.** 재색인이 필요 없고, ID가 없는 질문의 결과는 바뀌지 않는다.
B는 3,499건을 재색인해야 하고 분석기 변경으로 모든 검색 결과가 바뀔 위험이 있어 채택하지 않는다.
