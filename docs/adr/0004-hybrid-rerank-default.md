# ADR-0004: 서비스 검색 기본값 — 하이브리드(RRF) + 리랭크 N=20

- 상태: 채택 (2026-10-07)
- 이슈: #18 (PR ②)
- 결정한 사람: 소유자(miin-jun). 측정 결과를 본 뒤 정했다. 측정 전 예상은 커밋 4ee1cbb에 먼저 고정했다
- 관련: [ADR-0001 임베딩 모델](0001-embedding-model.md), [ADR-0002 리랭커](0002-reranker.md),
  [ADR-0003 BM25 요구사항 ID 가산](0003-requirement-id-boost.md), 측정 기록 [hybrid-search-measurement.md](../hybrid-search-measurement.md) 5절

## 결정

서비스 검색의 기본값은 **하이브리드(OpenSearch RRF, `rank_constant` k=60, 검색기별 후보 50) + 리랭크 N=20**
(`bge-reranker-v2-m3`)이다. 코드에서는 `search/hybrid.py`의 `hybrid_rerank_search(..., rerank_n=20, top_k=10)`이다.

## 근거

qa_v2 답 있는 51문항, 별칭 `rfp_chunks` → `rfp_chunks_v1_kure`(3,499건), 2026-10-07 측정.

| 조건 | run_id | R@10 전부 | MRR | 리랭크 p50 / p95 |
|---|---|---|---|---|
| k-NN (k=50) | `20261005T134118Z-os-knn-KURE-v1` | 30/51 | 0.317 | - |
| BM25 + ID 가산 | `20261006T141105Z-os-bm25` | 21/51 | 0.230 | - |
| 하이브리드 | `20261007T142117Z-os-hybrid-KURE-v1` | 30/51 | 0.348 | - |
| 하이브리드 + 리랭크 N=20 | `20261007T142136Z-os-hybrid-KURE-v1+rerank-bge-reranker-v2-m3-n20` | **33/51** | **0.497** | 230 / **528 ms** |
| 하이브리드 + 리랭크 N=50 | `20261007T142235Z-os-hybrid-KURE-v1+rerank-bge-reranker-v2-m3-n50` | 33/51 | 0.519 | 668 / 1140 ms |

- R@10은 N=20과 N=50이 33/51로 같다(McNemar 3:3, p=1.0). 같은 적중 수에서 리랭크 p95가 528ms로 N=50(1140ms)의
  절반 아래라 N=20을 고른다
- MRR은 k-NN 단독 0.317 → 0.497이다

## 한계

- **k-NN 단독(30/51)과 유의한 차이가 없다**(리랭크 N=20 대비 4:1, p=0.375). 51문항으로는 "하이브리드 + 리랭크가
  k-NN보다 낫다"고 말할 수 없다
- **하이브리드 단독은 30/51로 k-NN과 같다**(3:3, p=1.0). BM25·k-NN 양쪽 목록에 든 청크가 RRF 점수를 두 번 받아,
  BM25 후보 50 밖이고 k-NN에만 있는 정답을 10위 밖으로 밀어냈다 — q011(k-NN 3위 → 하이브리드 14위),
  q022(7위 → 19위), q053(4·10위 → 21·22위). 리랭크 N=20은 q011·q022를 1·2위로 되돌리지만, q053은 정답이
  21·22위라 리랭크 대상에 들지 못한다
- k-NN + 리랭크 조건은 같은 인덱스로 재지 않았다. 리랭커가 개선의 대부분을 낸 것인지 하이브리드가 기여한 것인지
  이 측정으로는 나눌 수 없다
- 1회 측정이다

## 재검토

#25에서 평가 세트를 늘린 뒤 **k-NN + 리랭크** 조건과 함께 다시 측정한다.
