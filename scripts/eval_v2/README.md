# qa_v2 추가 문항 작성 기록 (#15)

`data/eval/qa_v2.jsonl`의 q031~q056 초안을 만들 때 쓴 스크립트다. "후보를 무작위로 뽑았다"는
기록을 다시 확인할 수 있게 남긴다. 정답 선택에는 검색(BM25·벡터) 결과를 쓰지 않았다.
모두 레포 루트에서 `uv run python scripts/eval_v2/<파일>`로 실행한다.

| 파일 | 하는 일 |
|---|---|
| `sample.py [n]` | `SEED = 15`로 유형·문서 슬롯 26개를 배정하고, 슬롯마다 후보를 무작위 순서로 n개 출력 (`0`이면 슬롯만) |
| `ctx.py ctx <doc_id> <단위ID> [n]` / `ctx.py toc <doc_id>` | 단위 앞뒤 n개 문맥 / 제목처럼 보이는 블록과 요구사항 목록 (읽기용) |
| `absent.py <doc_id> <검색어...>` | 답 없음 문항의 부재 확인. 공백을 지운 원문 단위마다 검색어 포함 여부를 센다 |
| `append.py drafts.json` | 초안을 `EvalQuestionV2`로 만들어 qa_v2(30문항일 때만)에 덧붙인다 |
| `review.py scripts/eval_v2` | `drafts.json`과 qa_v2로 검수표 `data/tmp/review_v2.md`를 만든다 |
| `drafts.json` | 초안 26문항과 메타(원문 단위, 건너뛴 후보·이유, 부재 확인 검색어·목차, 애매한 점). 검수 전 상태 그대로다 |

## 재현할 때 주의

- `sample.py`는 후보에서 q001~q030(v1)의 정답 청크만 뺀다. 초안을 뽑을 때 qa_v2에 v1 30문항만
  있었기 때문이다. 처음에는 qa_v2의 모든 문항을 뺐는데, 추가 문항이 들어간 뒤 다시 돌리자 슬롯
  배정은 같았지만 슬롯별 후보 순서가 달라졌다. 제외 대상을 한정한 뒤 초안 작성 때의 출력과
  전문이 같은 것을 2026-09-26에 확인했다
- 검수 반영(2026-09-26) 이후 qa_v2는 `drafts.json`과 다르다 — q038은 답 있는 문항으로 바뀌었고
  q039·q042가 수정됐으며 q057이 추가됐다. 바뀐 내용은 각 문항의 `note`와 git 이력에 있다
